01

最初の一歩

クイックスタート

Node.js 20 以上のホストにインストールします。Runner はプロセスや Web サーバーを起動せず、プラグイン実行は callback が担当します。

npm install @dsh-plugin-evaluation/portable-runner@0.1.6
import { runPortableCasePlan } from '@dsh-plugin-evaluation/portable-runner'

const report = await runPortableCasePlan({
  plan: {
    schemaVersion: 1,
    id: 'portable-smoke',
    title: 'Portable runner smoke test',
    setup: [{ op: 'environment.set', name: 'EXPECTED', value: 'safe' }],
    steps: [{ op: 'plugin.prompt', input: 'answer' }],
    metrics: [{ id: 'expected-output', type: 'output.equals', expected: 'safe' }],
  },
  async runPlugin({ env }) { return { output: env.EXPECTED, exitCode: 0 } },
})

console.log(report.status) // passed
02

契約

Portable プラン

プランは制限された setup、明示的な plugin steps、再利用可能な metrics で構成されます。新しいプランでは steps と metrics を使用してください。

PLAN

PortableCasePlan

1 つの決定的な評価ケースを定義します。

schemaVersion
現在は 1。
setup
環境変数とワークスペース操作。
steps
plugin.prompt または登録済み操作。
metrics
一意な id と type を持つ指標。
SUITE

PortableSuite

再利用可能なケースと fixture lifecycle をまとめます。

fixtures
共有 setup と teardown hook。
cases
独立して実行されるケース。
version
provenance に記録される suite バージョン。
互換性旧来の run と assertions も正規化されますが、新しいプランでは steps と metrics を推奨します。
03

実行結果

Runner-native レポート

すべての単一ケース実行は同じレポート契約を返します。変換なしで保存、表示、統合境界を越えて受け渡せます。

reportSchemaVersion1
statuspassed · failed
checks構造化された指標結果
actualOutputプラグインの最終出力
summary成功 / 失敗ケース数
provenanceプランと呼び出し元の識別情報
evidenceファイル、呼び出し、メッセージ、timeout
{
  reportSchemaVersion: 1,
  reportId: 'uuid',
  runId: 'uuid',
  status: 'passed',
  checks: [{ id: 'expected-output', passed: true }],
  actualOutput: 'safe',
  summary: { totalCases: 1, passedCases: 1, failedCases: 0 },
  provenance: { schemeId: 'portable-smoke', schemeVersion: 1 },
  evidence: { files: [], toolCalls: [], messages: [] }
}
04

カスタマイズ

拡張ポイント

実行ループを変更せずに語彙を拡張できます。Registry は明示的で確認しやすい設計です。

const steps = createStepRegistry().register(
  'custom.prepare',
  (step, context) => { context.environment.PREPARED = String(step.value) },
)

const metrics = createMetricRegistry().register(
  'output.startsWith',
  ({ metric, output }) => output.startsWith(metric.expected),
)
STEPS

createStepRegistry

step と実行コンテキストを受け取る操作を登録します。

METRICS

createMetricRegistry

出力と evidence を評価する boolean evaluator。

REPORTERS

createReporterRegistry

JSON、Markdown、JUnit、独自形式を出力します。

05

境界

安全境界

  • 一時ワークスペース毎回新しい workspace を作り、finally で削除します。
  • パス制限相対パスのみ許可し、NUL、traversal、workspace 外への escape を拒否します。
  • ホストが実行を管理callback が process、network、filesystem、credentials の trust boundary です。
  • DSH 依存なしホスト非依存で、プロセスや Web サーバーを起動しません。
